# Agent 3 — ADR 2025 classification rules

This folder is owned by Agent 3. Its modules produce **provisional, evidence-scoped** Class 3, 6.1, 8 and 9 results only. No code here emits a global “not regulated for transport” determination. This repository was empty when the initial Agent 3 scaffold was created; the Lead Agent's shared schema and review workflow remain pending. Use a dedicated review branch for further work.

Regulatory baseline: UNECE ADR 2025, ECE/TRANS/352 (Vol. I), Chapters 2.1–2.2 and Part 3; Class 3 §2.2.3, Class 6.1 §2.2.61, Class 8 §2.2.8, Class 9 §2.2.9. Official source: https://unece.org/sites/default/files/2025-01/2412006_E_ECE_TRANS_352_Vol.I_WEB_0.pdf

**Status: development only. Not independently reviewed or validated.**
